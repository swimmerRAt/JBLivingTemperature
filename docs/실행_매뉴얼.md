# 전북 생활권 인사이트 · 실행 매뉴얼

프로젝트를 처음 설치해서 데이터베이스를 만들고, 예측 모델을 학습하고, 대시보드로 시연하기까지의 순서입니다.
명령어는 모두 **프로젝트 루트 폴더**(`JBLivingTemperature/`)에서 실행합니다.

- 서비스가 무엇을 보여 주는지: [서비스 명세](서비스_명세.md)
- 원천 데이터의 범위와 품질 문제: [DB 구축 상태](database.md)
- 모델 성능과 예측 결과: [예측 모델 결과 보고서](model_report.md)

## 어떤 방법으로 시연할까?

| 상황 | 방법 | 걸리는 시간 |
| --- | --- | --- |
| 이미 구축된 DB 파일을 받았다 | [A. 빠른 시연](#a-빠른-시연-db-파일이-있을-때) | 약 3분 |
| 처음부터 데이터를 모두 받아 DB를 만든다 | [B. 전체 구축](#b-전체-구축-처음부터) | 약 1시간 30분 (대부분 버스 노선 수집) |

`data/` 폴더는 용량(약 800MB)과 인증키 때문에 Git에 올리지 않습니다. 다른 컴퓨터에서 시연하려면 A 방법의 파일 2개를 따로 전달하거나 B 방법으로 새로 구축합니다.

## 0. 공통 준비

### 0-1. 필요한 프로그램

| 프로그램 | 용도 | 확인 명령 |
| --- | --- | --- |
| Python 3.11 이상 | 전체 파이프라인과 대시보드 | `python3 --version` |
| Node.js 18 이상 | B 방법의 HIRA 병의원 ZIP 다운로드에만 필요 | `node --version` |

### 0-2. 파이썬 가상환경과 패키지 설치

```bash
python3 -m venv --system-site-packages .venv
.venv/bin/python -m pip install -r requirements.txt
```

`--system-site-packages`는 시스템에 이미 깔린 패키지를 재사용하는 옵션입니다. 이 옵션을 쓰면 `streamlit` 명령이 `.venv/bin`에 생기지 않으므로, 아래처럼 항상 `.venv/bin/python -m streamlit`으로 실행합니다.

설치가 잘 됐는지 테스트로 확인합니다. DB가 없으면 DB가 필요한 테스트는 건너뜁니다.

```bash
.venv/bin/python -m pytest -q tests
```

## A. 빠른 시연 (DB 파일이 있을 때)

### A-1. 파일 2개를 제자리에 놓기

| 파일 | 위치 |
| --- | --- |
| 원천 DB | `data/processed/living_areas.sqlite` (약 210MB) |
| 읍면동 경계 | `data/raw/sgis/boundary_town_2024.json` |

이미 구축된 컴퓨터에서 두 파일을 묶는 명령입니다.

```bash
tar -czf demo_data.tar.gz data/processed/living_areas.sqlite data/raw/sgis/boundary_town_2024.json
# 시연할 컴퓨터의 프로젝트 루트에서
tar -xzf demo_data.tar.gz
```

### A-2. 예측 모델 학습과 대시보드 데이터 만들기

```bash
.venv/bin/python scripts/train_models.py
```

한 번 실행하면 아래 4단계가 차례로 돌고 약 30초~1분 걸립니다.

1. 읍면동 청년 순이동 추정 (코호트 잔차법)
2. 사업체 쇠퇴 위험 예측 (도시재생법 기준, 전체 사업체·업종별)
3. 청년 인구 3년 예측 (LightGBM, 해밀턴-페리 기준선과 비교)
4. 대시보드용 읍면동 패널 갱신

마지막 줄에 `done: 242 towns`가 나오면 성공입니다. 결과는 다음 위치에 저장됩니다.

| 결과 | 위치 |
| --- | --- |
| 결과 보고서 | `docs/model_report.md` |
| 성능 지표 | `models/model_report.json` |
| 예측 CSV | `data/processed/forecast_youth.csv`, `forecast_business_town.csv`, `forecast_business_sector.csv` 등 |
| 대시보드 입력 | `data/processed/region_panel.csv`, `data_quality.json` |

### A-3. 대시보드 실행

```bash
.venv/bin/python -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501
```

브라우저에서 <http://localhost:8501>을 엽니다. 서버 컴퓨터에서 실행했다면 VS Code의 포트 전달(Ports 탭)로 8501번을 열면 됩니다.
`--server.address 127.0.0.1`은 같은 컴퓨터에서만 접속되게 하는 옵션입니다. 외부 공개가 필요하지 않다면 그대로 둡니다.

## B. 전체 구축 (처음부터)

### B-1. 인증키 발급과 입력

| 변수 | 발급처 | 용도 |
| --- | --- | --- |
| `KOSIS_API_KEY` | [KOSIS 공유서비스](https://kosis.kr/openapi/) 회원가입 후 인증키 신청 | 인구·이동·빈집·주택·의료 집계·대중교통 통계 |
| `DATA_GO_KR_API_KEY` | [공공데이터포털](https://www.data.go.kr) 활용신청: [버스정류소정보](https://www.data.go.kr/data/15098534/openapi.do), [버스노선정보](https://www.data.go.kr/data/15098529/openapi.do) | TAGO 버스 정류장·노선 |
| `SGIS_CONSUMER_KEY` | [SGIS 개발지원센터](https://sgis.mods.go.kr/developer/) 서비스 신청 → 서비스 ID | 읍면동 사업체·인구·경계 |
| `SGIS_CONSUMER_SECRET` | 위와 같음 → 보안 키 | |

`.env.example`을 복사해 `.env`를 만들고 값을 따옴표 없이 넣습니다. `.env`는 Git에 올라가지 않습니다.

```bash
cp .env.example .env
# .env 파일을 열어 각 줄의 = 뒤에 키를 붙여 넣고 저장
```

### B-2. 원천 데이터 다운로드

모든 다운로드 스크립트는 **이미 받은 파일은 건너뜁니다.** 중간에 끊기면 같은 명령을 다시 실행하면 이어서 받습니다. 다시 받고 싶으면 `--force`를 붙입니다.

```bash
P=.venv/bin/python

# ① 주민등록 인구 2008~2025 (행정안전부, 성별·5세 연령대, 키 불필요, 약 2분)
$P scripts/download_mois_population.py

# ② KOSIS 통계 (약 5분)
$P scripts/download_kosis_api.py --table registered_population --start 2001 --end 2007
$P scripts/download_kosis_api.py --table migration_age  --start 2001 --end 2025
$P scripts/download_kosis_api.py --table migration_sex  --start 2001 --end 2025
$P scripts/download_kosis_api.py --table migration_rate --start 2001 --end 2025
$P scripts/download_kosis_api.py --table business_town  --start 2020 --end 2020
$P scripts/download_kosis_api.py --table vacant_housing --start 2015 --end 2025
$P scripts/download_kosis_api.py --table housing_types  --start 2015 --end 2025
$P scripts/download_hira_quarterly.py       # 시군구 의료기관 분기 집계
$P scripts/download_transport_api.py        # 대중교통 접근수단·시간·이용횟수

# ③ SGIS 읍면동 사업체 2000~2024, 등록센서스 인구 2015~2024, 경계 (약 15분)
$P scripts/download_sgis_api.py

# ④ TAGO 버스 정류장·노선·노선별 경유 정류장 (약 45분, 가장 오래 걸림)
$P scripts/download_tago_api.py --dataset all
```

⑤ HIRA 병의원·약국 ZIP은 공개 페이지가 직접 다운로드 주소를 주지 않아, 헤드리스 크롬으로 링크를 누르는 스크립트를 씁니다(ZIP 8개, 약 500MB).

```bash
cd scripts/hira && npm install && npx playwright-core install chromium && cd ../..
node scripts/hira/download.js data 2023.12 2024.12 2025.3 2025.6 2025.9 2025.12 2026.3 2026.6
```

이미 크롬이 설치돼 있으면 `npx ... install chromium` 대신 경로를 지정할 수 있습니다.

```bash
CHROMIUM_PATH=/usr/bin/chromium-browser node scripts/hira/download.js data 2026.6
```

새 분기 파일이 공개되면 기간을 추가해 같은 명령을 실행합니다. 공개된 기간은 [HIRA 공개 페이지](https://opendata.hira.or.kr/op/opc/selectOpenData.do?sno=11925)에서 확인합니다.

### B-3. 원천 DB 만들기

```bash
.venv/bin/python scripts/build_living_database.py
```

약 3분 걸리고, 마지막에 `database: .../data/processed/living_areas.sqlite`가 나오면 성공입니다.
DB는 임시 파일로 먼저 만든 뒤 무결성 검사(행 합계·외래키·시군 수)를 통과해야 교체됩니다. 실패하면 기존 DB는 그대로 남고 오류 원인이 출력됩니다.

### B-4. 예측 학습과 대시보드

A 방법의 [A-2](#a-2-예측-모델-학습과-대시보드-데이터-만들기)와 [A-3](#a-3-대시보드-실행)을 그대로 실행합니다.

```bash
.venv/bin/python scripts/train_models.py
.venv/bin/python -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501
```

## 시연 순서 예시

1. 사이드바에서 **시군 → 읍면동**을 고릅니다. 예: 임실군 관촌면(위험 사례), 전주시 효자5동(안정 사례)
2. 상단 카드에서 생활 점수, 상대 등급, **3년 후 청년 인구**, **3년 감소 위험**을 봅니다.
3. 사이드바 **지도 색상**을 '3년 감소 위험'으로 바꿔 전북 전체의 위험 분포를 봅니다.
4. **3년 내 감소 위험 (예측)** 표에서 지방소멸위험지수와 도시재생법 사업체 쇠퇴 기준 해당 여부, 먼저 쇠퇴할 업종을 설명합니다.
5. **추천 가중치** 슬라이더를 움직여 추천 지역 순위가 바뀌는 것을 보여 줍니다.
6. 화면 하단의 판단 기준 안내와 자료 출처, `docs/model_report.md`의 백테스트 성능표로 근거를 설명합니다.

## 데이터를 새로 고칠 때

| 상황 | 명령 |
| --- | --- |
| 새 연도 인구·통계 공표 | 해당 다운로드 명령의 `--end`를 새 연도로 바꿔 실행 → B-3 → A-2 |
| 버스 정류장·노선 최신화 | `$P scripts/download_tago_api.py --dataset all --force` → B-3 → A-2 |
| 새 HIRA 분기 공개 | `node scripts/hira/download.js data <새 기간>` → B-3 → A-2 |
| 판단 기준·모델 코드 수정 | A-2만 다시 실행 |

## 자주 생기는 문제

| 증상 | 원인과 해결 |
| --- | --- |
| `KOSIS_API_KEY is empty` 등 키가 비었다는 메시지 | `.env`에 값을 넣고 **저장**했는지 확인. `=` 뒤에 공백·따옴표 없이 입력 |
| SGIS 인증 `HTTP Error 412` | SGIS 키가 비었거나 서비스 ID·보안 키가 바뀌어 들어감 |
| TAGO `가용한 세션` 오류가 반복 | 공공데이터포털 일일 호출 한도. 다음 날 같은 명령을 다시 실행하면 이어서 받음 |
| `female age columns missing` (DB 빌드 실패) | 예전에 성별 없이 받은 주민등록 파일. `$P scripts/download_mois_population.py --force` |
| `sgis_business_town is empty` 또는 경계 파일 없음 | B-2 ③ SGIS 다운로드를 먼저 실행 |
| 대시보드에 "예측 결과가 연결되지 않았습니다" | `scripts/train_models.py`를 실행하지 않았거나 실패함 |
| `streamlit: command not found` | `.venv/bin/python -m streamlit run app.py`로 실행 |
| 포트 8501이 이미 사용 중 | `--server.port 8502`처럼 다른 번호 사용 |
| 지도 배경이 안 보임 | 지도 타일(OpenStreetMap)은 인터넷 연결이 필요. 오프라인 시연 시 점 위치와 표만 표시됨 |

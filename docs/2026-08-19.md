## 2) 발견된 문제 사항

### 실행/환경 문제
- 시스템 Python 환경에 직접 `pip install` 실패 (externally-managed-environment)
  - 조치: `.venv` 생성 후 가상환경 기반 설치로 해결
- 샌드박스에서 `.venv/bin/python` 또는 streamlit 실행 시 `Operation not permitted` 발생
  - 조치: unsandboxed 실행으로 우회
- 8501 포트 충돌 발생
  - 조치: 8502/8503/8504 등 대체 포트 사용

### 코드/로직 문제
- 초기 앱 실행 시 `KeyError: 'lat'` 발생
  - 원인: `region_latest.csv`에 좌표 컬럼 누락
  - 조치: `scripts/calculate_scores.py` 출력 컬럼에 `lat`, `lon` 추가
- 추천 탭에서 조건 미충족 지역 0개일 때 처리 필요
  - 조치: 앱 중단 대신 경고/안내 메시지 출력하도록 개선

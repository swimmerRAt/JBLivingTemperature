# 데이터셋 정리

이 문서는 `data/` 폴더에 있는 실제 데이터셋을 분석용 관점에서 카테고리화한 것이다. 행 수는 CSV의 헤더 행을 제외한 데이터 행 기준이며, 열 수는 원본 파일의 물리 컬럼 수 기준이다.

## 전체 카테고리

| 카테고리 | 데이터셋 | 주요 활용 |
|---|---:|---|
| 인구/장래인구 | 3 | 전북 및 시군구별 인구 구조, 연령계층, 출생/사망/이동 요인 분석 |
| 인구 이동 | 2 | 시도/시군구 단위 전입, 전출, 순이동 흐름 분석 |
| 산업/고용 | 3 | 산업, 직업, 교육정도별 취업자 구조 분석 |
| 주거 | 2 | 빈집, 전체주택, 주택 유형 구성 분석 |
| 의료/요양기관 | 2개 CSV/ZIP 묶음 | 요양기관 수, 병의원/약국 위치 및 상세 서비스 분석 |
| 교통 | 3 | 시도별 대중교통 접근수단, 접근시간, 이용횟수 분석 |
| 메타데이터 | 1 | 원천 링크와 수집 메모 |

## 공통 구조 메모

- KOSIS 분석 CSV는 대부분 wide format이다. 앞쪽에는 지역, 성별, 연령 같은 축 컬럼이 있고, 뒤쪽에는 `연도/분기 x 세부 항목 x 원데이터/증감/증감률` 형태의 다중 헤더 측정값 컬럼이 반복된다.
- `전년 대비 증감`, `전년 대비 증감률`, `전분기 대비 증감`, `전분기 대비 증감률`은 원천에서 계산된 파생 지표다. `데이터셋 링크.txt`에 "증감률은 오차있을 수 있음"이라고 적혀 있으므로, 의사결정용 분석에서는 원데이터로 재계산하는 편이 좋다.
- `시군구 성별이동자수 분기별.csv`, `연령별 이동자수 분기별.csv`는 CP949 인코딩이고, 나머지 CSV는 UTF-8 BOM 기준으로 읽힌다.
- `전국 병의원 및 약국 현황 2025.6.zip`과 `전국 병의원 및 약국 현황 2025.6 (1).zip`은 같은 스냅샷으로 보이며 파일 크기와 내부 행 수가 동일하다.

## 분석용 정규화 제안

wide format CSV는 바로 모델링하기보다 아래처럼 long format으로 변환해 두면 병합과 시각화가 쉬워진다.

| 원본 구조 | 권장 long format 컬럼 |
|---|---|
| `연도 x 항목 x 원데이터/증감/증감률` | 축 컬럼 + `year` + `category` + `metric_name` + `value_type` + `value` |
| `분기 x 기관종별 x 원데이터/증감/증감률` | `region` + `quarter` + `institution_group` + `institution_type` + `value_type` + `value` |
| 이동자수 월/분기 컬럼 | `region` + `sex_or_age` + `movement_type` + `period` + `period_type` + `value` |
| 병의원/약국 XLSX 패키지 | `snapshot_period` + 각 서비스 원본 컬럼, 서비스 간 조인키는 `암호화요양기호` |
